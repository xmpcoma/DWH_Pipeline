## 🧹 Дополнительная очистка после загрузки в БД

После загрузки данных в PostgreSQL и проверки целостности связей были обнаружены "висящие" записи — ссылки на сущности, которых нет в справочниках:

- **68 заказов** ссылались на несуществующих клиентов
- **82 события** без клиента
- **116 событий** без товара

**Решение:** Удалить эти записи из БД, так как они не могут быть корректно использованы в аналитике (невозможно сделать JOIN с клиентами/товарами).

**Итоговое количество записей после очистки:**

| Таблица | До очистки | После очистки |
|---------|-----------|---------------|
| customers | 701 | 701 |
| products | 600 | 600 |
| orders | 1 200 | 1 132 |
| payments | 821 | 781 |
| events | 1 500 | 1 305 |

После удаления все проверки целостности показывают **0** — ни одной "висящей" записи не осталось.
